# SolarSystemSimulator
Final project for the 420-SF3-RE Program Developmenet in a Graphical Environment course at Vanier.
Currently a simple simulation of the solar system with the sun and the 8 planets, with the aim of becoming a useful educational tool.

### Usage
1. Clone the repo and open it in NetBeans
2. Download the required dependencies using Maven
3. Run the main application file: `App.java`
4. Start a new simulation by clicking on the `New Simulation` button in the main menu

### Controls
- `W/A/S/D`: Move the camera left/right/down/up
- `Escape`: Open the pause menu
